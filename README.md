# BUG BUSTER

A fast arcade shooter in one HTML file. Debug the universe: shoot bugs like NullPointer, 404 and SyntaxError.

**Play:** https://zyadhassana9-code.github.io/bug-buster/

## Features
- Boss fights every 3 levels
- 5 power-ups: triple shot, shield, bomb, slow-mo, extra life
- Combo multiplier, sound effects, high score saved in the browser

## Controls
Mouse, touch or arrow keys to move. Auto-fire. B = bomb, P = pause, M = mute. Space or tap to start.

Made with plain HTML, CSS and JavaScript (canvas + WebAudio). No dependencies.
